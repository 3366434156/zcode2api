一键接入做了什么
· 只往客户端配置里写一条 provider（id 固定为 zcode2api），其它 provider、routing group、自定义字段原样保留。
· 写入前自动备份原件（首次接入前的版本永久保留），文件以 0600 落盘，采用临时文件 + 原子替换。
· 「一键还原」回到首次接入前的字节；若期间你或客户端自己改过该文件，则只摘掉本网关那一条，不覆盖你的改动。
· 客户端不在本机（例如 magpie 跑在另一台电脑）时，可改用命令行： python -m app.clients apply --client magpie --base-url <网关地址> --key <网关 Key>
